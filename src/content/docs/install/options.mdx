## Переменные

Параметры передаются переменными окружения после `|`, перед `ash` или `sh`:

<Tabs syncKey="platform">
<TabItem label="OpenWrt">

```shell
wget -O - https://raw.githubusercontent.com/prettyleaf/openwrt-exodus/main/install.sh | VERSION=v1.30.7 CORE=alpha ash
```

</TabItem>
<TabItem label="Keenetic">

```shell
curl -fsSL https://raw.githubusercontent.com/prettyleaf/openwrt-exodus/keenetic/install.sh | CORE=alpha PASSWORD=secret sh
```

</TabItem>
<TabItem label="Asus">

```shell
curl -fsSL https://raw.githubusercontent.com/prettyleaf/openwrt-exodus/asuswrt/install.sh | CORE=alpha sh
```

</TabItem>
</Tabs>

| Переменная | Платформы | Значение |
| --- | --- | --- |
| `CORE` | все | `meta`, `alpha`, `prizrak`, `prizrak-kroha` или `prizrak-kroha-upx` (два последних — только OpenWrt) — поставить это [ядро](#ядро) без вопроса |
| `GH_PROXY` | все | адрес [gh-proxy](#если-github-заблокирован) с токеном, например `https://example.com/ghproxy/TOKEN`; `GH_PROXY=` — скачивать только напрямую, без публичных зеркал |
| `LOW_SPACE=1` | все | удалить текущее ядро перед установкой нового, если на накопителе мало места |
| `VERSION` | OpenWrt | релиз вместо последнего, например `v1.30.7` |
| `SUBSCRIPTION` | OpenWrt | ссылка на [подписку](#подписка-при-установке): установщик добавит её, скачает для проверки и сделает профилем |
| `PASSWORD` | Keenetic | пароль веб-интерфейса при первой установке, не короче 4 символов. Без него установщик спрашивает пароль, Enter без пароля — веб-интерфейс без входа |
| `REF` | Keenetic, Asus | ветка или тег вместо `keenetic` / `asuswrt` |

Выбранные ядро и gh-proxy сохраняются (`/etc/config/nikki` на OpenWrt, `/opt/etc/exodus/config.json` на Keenetic и Asus): следующие запуски установщика и страница обновлений используют их.

## Подписка при установке

На OpenWrt установщик может сразу добавить подписку, тогда после установки её не нужно вводить в LuCI. Ссылку возьмите в одинарные кавычки: в ней бывают `&` и `?`, без кавычек консоль обрежет ссылку.

```shell
wget -O - https://raw.githubusercontent.com/prettyleaf/openwrt-exodus/main/install.sh | SUBSCRIPTION='https://example.com/sub/TOKEN' ash
```

- Ссылка проверяется до установки: она должна начинаться с `https://` или `http://` и быть без пробелов. В выводе виден только адрес сервера, токен из ссылки не печатается.
- После пакетов и ядра установщик добавляет подписку на страницу **«Профиль»**: при новой установке — вместо подписки-заглушки, иначе — новой подпиской. Если такая ссылка уже добавлена, берётся она, её имя и настройки не меняются. Заголовки HWID включены, как у подписки, добавленной в LuCI.
- Подписка сразу скачивается, чтобы проверить ссылку, и становится профилем. Имя и срок действия приходят от провайдера.
- Если Exodus ещё выключен, в терминале установщик спрашивает, включить ли его с этой подпиской (Enter — да). Какие устройства идут через прокси, выбирается в **«Настройки приложения»**.
- Если подписка не скачалась, установщик показывает строки журнала с причиной, а подписка остаётся на странице **«Профиль»** — там можно исправить ссылку. Если Exodus уже работал, он остаётся на прежнем профиле.

## Ядро

В терминале установщик спрашивает ядро, Enter оставляет текущее. `CORE=` выбирает его без вопроса.

| Ядро | `CORE` | Что ставится |
| --- | --- | --- |
| Mihomo Meta | `meta` | последний стабильный релиз [MetaCubeX/mihomo](https://github.com/MetaCubeX/mihomo/releases) |
| Mihomo Alpha | `alpha` | последняя сборка для разработки, [Prerelease-Alpha](https://github.com/MetaCubeX/mihomo/releases/tag/Prerelease-Alpha) |
| Prizrak-Core | `prizrak` | последний релиз [legiz-ru/Prizrak-Core](https://github.com/legiz-ru/Prizrak-Core/releases), форка mihomo, по умолчанию при новой установке |
| Prizrak-Kroha | `prizrak-kroha` | облегчённая сборка Prizrak-Core из того же релиза для роутеров с малым флешем: ≈ 35–40 МБ на флеше. Только OpenWrt: amd64, arm64, armv7, mips, mipsle |
| Prizrak-Kroha UPX | `prizrak-kroha-upx` | та же сборка, сжатая UPX: ≈ 8–10 МБ на флеше, при запуске распаковывается в оперативную память |

Ядро скачивается из релизов на GitHub под архитектуру роутера, повторный запуск установщика и страница обновлений обновляют его до последней сборки. На флеш пишется только выбранное ядро: на OpenWrt с 1.31.0 его не ставит ни один пакет, Mihomo Meta скачивается так же, как остальные, из последнего стабильного релиза. Пакет `mihomo-meta` прежних версий установщик удаляет, его ядро остаётся и обновляется.

## Если GitHub заблокирован

Установщик сначала проверяет доступ к GitHub и перебирает пути по очереди:

1. сохранённый gh-proxy, если он есть;
2. напрямую. Если GitHub не ответил, установщик пишет причину, например `github does not answer directly: curl: (6) Could not resolve host` — что она значит, см. в [решении проблем](/troubleshooting/#установщик-пишет-что-github-недоступен);
3. на OpenWrt — через GitHub API, если заблокирован только `github.com`, а `api.github.com` и `release-assets.githubusercontent.com` отвечают. Установщик берёт метаданные релиза из API и скачивает файлы по их id, ничего настраивать не нужно, в выводе будет `through the GitHub API`;
4. публичные зеркала `gh-proxy.com` и `ghfast.top`. Сработавшее зеркало сохраняется, как свой gh-proxy, и страница обновлений качает через него.

Файлы, скачанные через публичное зеркало, оно может подменить, проверить их нечем: если есть свой сервер, лучше свой gh-proxy. Через `GH_PROXY=` установщик снова качает только напрямую (на OpenWrt — и через GitHub API), через `GH_PROXY=<адрес>` — только через этот адрес.

Если не ответили и зеркала, установщик проверяет [jsDelivr](https://www.jsdelivr.com/): если тот доступен, GitHub блокирует провайдер; если нет — у роутера, скорее всего, нет интернета или DNS. jsDelivr отдаёт файлы репозитория, но не файлы релизов, поэтому пакеты и ядро скачиваются только с GitHub.

Тогда нужен свой [gh-proxy](https://github.com/prettyleaf/gh-proxy) на сервере с доступом к GitHub. Его адрес с токеном выглядит как `https://example.com/ghproxy/TOKEN`. В терминале установщик сам спросит адрес. Его можно передать и заранее, скачав установщик через тот же gh-proxy или с jsDelivr:

<Tabs syncKey="platform">
<TabItem label="OpenWrt">

```shell
# через gh-proxy
wget -O - https://example.com/ghproxy/TOKEN/https://raw.githubusercontent.com/prettyleaf/openwrt-exodus/main/install.sh | GH_PROXY=https://example.com/ghproxy/TOKEN ash
# установщик с jsDelivr, он может отставать от репозитория на несколько часов
wget -O - https://cdn.jsdelivr.net/gh/prettyleaf/openwrt-exodus@main/install.sh | GH_PROXY=https://example.com/ghproxy/TOKEN ash
```

</TabItem>
<TabItem label="Keenetic">

```shell
# через gh-proxy
curl -fsSL https://example.com/ghproxy/TOKEN/https://raw.githubusercontent.com/prettyleaf/openwrt-exodus/keenetic/install.sh | GH_PROXY=https://example.com/ghproxy/TOKEN sh
# установщик с jsDelivr, он может отставать от репозитория на несколько часов
curl -fsSL https://cdn.jsdelivr.net/gh/prettyleaf/openwrt-exodus@keenetic/install.sh | GH_PROXY=https://example.com/ghproxy/TOKEN sh
```

</TabItem>
<TabItem label="Asus">

```shell
# через gh-proxy
curl -fsSL https://example.com/ghproxy/TOKEN/https://raw.githubusercontent.com/prettyleaf/openwrt-exodus/asuswrt/install.sh | GH_PROXY=https://example.com/ghproxy/TOKEN sh
# установщик с jsDelivr, он может отставать от репозитория на несколько часов
curl -fsSL https://cdn.jsdelivr.net/gh/prettyleaf/openwrt-exodus@asuswrt/install.sh | GH_PROXY=https://example.com/ghproxy/TOKEN sh
```

</TabItem>
</Tabs>

- Адрес сохраняется, следующие запуски и страница обновлений скачивают через него. Если сохранённый gh-proxy не работает, установщик пробует скачать напрямую, затем через публичные зеркала.
- Если в gh-proxy задан `GHP_ALLOW_LIST`, разрешите в нём `prettyleaf/openwrt-exodus`, `MetaCubeX/mihomo` и `legiz-ru/Prizrak-Core` (на OpenWrt Mihomo Meta приходит в пакетах, `MetaCubeX/mihomo` нужен для Alpha), на Keenetic, MikroTik и Asus — ещё `mikefarah/yq`. На неверный токен и репозиторий вне списка gh-proxy отвечает 404.
- На OpenWrt можно поставить пакеты и без gh-proxy, из архива релиза: [установка без доступа к GitHub](/install/openwrt/#установка-без-доступа-к-github).
