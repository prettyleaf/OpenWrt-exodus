На OpenWrt Exodus настраивается в LuCI: **«Службы» → «Exodus»**. Для работы достаточно двух страниц — «Профиль» и «Настройки приложения».

## Настройки приложения

- Если провайдер подписки присылает анонс, он показывается сверху, по центру.
- **Служба**: слева версии приложения и ядра, профиль и состояние прокси, справа — профиль, кнопка включения, «Автозапуск» и «Открыть панель», которая ведёт на страницу [«Панель управления»](#панель-управления).
  - **Профиль** — подписка или загруженный файл, сохраняется кнопкой «Сохранить и применить».
  - **Кнопка включения** показывает состояние: «Выключено», «Включается…», «Включено». Нажатие сразу запускает или останавливает сервис и сохраняет это в настройках (флаг `enabled`), так что выключенный сервис не запустится и после перезагрузки. Она заменила флажок «Включить» и кнопку «Перезапустить сервис».
  - **«Автозапуск»** — запуск при загрузке роутера, то же, что `/etc/init.d/nikki enable` / `disable` и «Система» → «Загрузка». Применяется сразу.
- **Задержка запуска** — секунды ожидания после загрузки роутера.
- **Запланированный перезапуск** — по cron, по умолчанию `0 3 * * *` (каждый день в 3:00).
- **Проверить профиль** — проверять профиль ядром перед запуском (включено). Если проверка не прошла, сервис не запускается, причина — в логе ядра.
- **Только ядро** — запустить ядро с профилем как есть: без mixin и без правил перехвата.
- **Устройства**: режим «Исключение: проксировать все устройства, кроме выбранных» (по умолчанию) или «Добавление: проксировать только выбранные устройства» и сами устройства — по MAC или IP. IP известного устройства сохраняется как его MAC, так что совпадает и IPv4-, и IPv6-трафик устройства; IP неизвестного устройства совпадает только с этим адресом. Выбор хранится в «Расширенные» → «LAN-прокси» → «Контроль доступа».

## Панель управления

Панель ядра ([MIBoard](https://github.com/blagodaren/miboard) по умолчанию) прямо в LuCI: выбор прокси в группах, соединения, логи. Над ней — «Обновить панель» и «Открыть в новой вкладке». Панель доступна, пока сервис работает, ядро скачивает её при первом запуске. Если LuCI открыт по HTTPS, а ядро отдаёт панель по HTTP, браузер не покажет её на странице — откройте её в новой вкладке.

## Профиль

Подписки (название, URL подписки, URL сведений о подписке, User-Agent, интервал обновления, «Передавать HWID»), кнопки «Обновить» и «Жёсткое обновление», загрузка своих профилей. Поля одинаковы на всех платформах — см. [Подписки и профили](/usage/subscriptions/).

## Редактор

Правка файлов: файл для mixin, профиль для автозапуска, профили, подписки, провайдеры правил и прокси.

## Журнал

Лог приложения и лог ядра, очистка при остановке и запланированная очистка по размеру. **«Отладочный лог» → «Сформировать и скачать»** — отчёт для issue.

## Обновить

Установленные и последние версии пакетов и ядра, свободное место на флеше. «Обновить» запускает [установщик](/install/openwrt/#установка-и-обновление) с ядром и gh-proxy, выбранными в прошлый раз; настройки, профили и подписки сохраняются. Режим «мало места» удаляет текущее ядро перед установкой нового.

## Расширенные

:::caution
Для опытных пользователей. Неверные значения могут сломать прокси или доступ в интернет всей сети.
:::

| Раздел | Что внутри |
| --- | --- |
| **Настройки прокси** | включение перехвата; режимы TCP и UDP (Redirect, TPROXY, TUN; по умолчанию TCP Redirect, UDP TPROXY); перехват DNS и прокси для IPv4 и IPv6 |
| ↳ Прокси роутера | проксирование трафика самого роутера и его контроль доступа |
| ↳ LAN-прокси | входящие интерфейсы (по умолчанию `lan`) и контроль доступа — правила выбора устройств, проверяются сверху вниз |
| ↳ Обход | порты TCP и UDP для прокси, обход по DSCP и fwmark, обход IP материкового Китая |
| ↳ Прочее | зарезервированные сети IPv4 и IPv6 (идут напрямую), таймауты TUN, [HWID](/usage/subscriptions/#hwid) и заголовки, отправляемые подписке |
| **Опции mixin** | что Exodus задаёт поверх профиля, см. [Оверрайды](/usage/overrides/) |
| ↳ Основные | уровень логов, режим, исходящий интерфейс, IPv6, TCP keep-alive |
| ↳ Внешнее управление | панель (по умолчанию MIBoard, другую ядро скачает при следующем запуске) и её обновление, адрес и секрет API |
| ↳ Входящие | порты HTTP, SOCKS, смешанный (7890), Redirect (7891), TPROXY (7892), авторизация |
| ↳ TUN, DNS, сниффер | параметры TUN; DNS (по умолчанию Fake-IP `198.18.0.1/16`, листенер `[::]:1053`), hosts, серверы и политики DNS; сниффер |
| ↳ Правила, GeoX | свои правила и провайдеры правил поверх профиля; базы GeoIP/GeoSite и их автообновление |
| ↳ Содержимое файла mixin | «Включить» — применять [mixin-файл](/usage/overrides/#mixin-файл) (по умолчанию выключено), сам файл правят на странице «Редактор» |
| **Окружение, procd, RLIMIT** | переменные окружения ядра, быстрая перезагрузка, лимиты процесса |
